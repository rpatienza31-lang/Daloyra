# Daloyra

Simple accounting and business tracking for small business owners.

- `SPEC.md` — product and technical specification (source of truth)
- `PROGRESS.md` — phase status and decisions
- `CLAUDE.md` — conventions for contributors and Claude Code

## Run locally

1. Copy `.env.example` to `.env.local` and fill in the Supabase values.
2. `npm install`
3. `npm run dev` and open http://localhost:3000

## Checks

`npm run check` (lint, typecheck, unit tests) · `npm run build` · `npm run test:e2e`
